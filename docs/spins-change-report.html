SPINS 0.3: automatic publication numbering

The application now renders recursive SPINS publications with generated numbering, mixed prose and supporting tables, figures, lists, notes, and references. Authors supply hierarchy and instructions. Optional stable names identify amendment and reference targets; printed labels are not authored.

Numbering runs after mission amendments are applied. Cross-references and contents use the same generated numbering as the publication. Standing source documents remain unchanged.

Limits and standards

All SPINS-001–013 feature acceptance criteria have supporting tests or inspection. The full formatting/lint gate is not clean for the reasons above. The Markdown viewer must support embedded HTML lists and image data URLs. The HTML and PDF outputs provide the complete visual publication.

The ATO model remains an external proposal; its integration with SPINS 0.3 is unverified. This work implements publication authoring, not operational validation or simulator/interchange conformance. Research examples establish representational needs rather than one mandatory chapter outline.

Applied standards: RQM-001–007, DM-001–005/017, ARCH-002/014, FUNC-001–005/013, TEST-001–003/007/008/011/019, COMM-015–022, and TASK-001–007. Repository-wide formatting and lint completion remains unsatisfied. No commit, push, or publication was performed.
