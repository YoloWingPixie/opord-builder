## Part I Standing instructions

<a id="node-general"></a>

### 1 General

<a id="node-purpose"></a>

**1.1** **Purpose.** These fictional instructions demonstrate a numbered SPINS publication. They are not real-world flight procedures.


<a id="position-content-0-0-1"></a>

**1.2** **Applicability.** These standing instructions apply to the exercise participants. Mission-period changes identify the baseline revision they amend.


<a id="position-content-0-0-2"></a>

**Note 1.** *Paragraph numbers and cross-references update automatically when instructions are inserted, moved, or removed.*

### 2 Communications

<a id="node-check-in"></a>

**2.1** **<u>Initial check-in.</u>** Use the exercise control channel in [Table 1](#node-channel-table). Give callsign, position, altitude, and assigned mission.


<a id="node-channel-table"></a>

**Table 1. Exercise communications**

| Agency | Frequency | Purpose |
| :--- | ---: | :--- |
| MAGIC | 254.000 MHz AM | Exercise control |
| NORTH TOWER | 250.000 MHz AM | Local airfield coordination |

<a id="node-reports"></a>

**2.2** **Reports.** Report the change in status using the published call sequence.

<a id="position-content-0-1-2-0"></a>

**2.2.1** Use the assigned mission number when identifying the task.

<a id="position-content-0-1-2-0-0"></a>

**2.2.1.1** If a report requires clarification, retain the original report context.

<a id="position-content-0-1-2-0-0-0"></a>

**2.2.1.1.1** Clearly identify the corrected item.

<a id="node-deep-report"></a>

**2.2.1.1.1.1** A correction does not change unrelated instructions.

<a id="node-restrictions"></a>

#### 3.2 Restrictions

<a id="node-area-entry"></a>

**3.2.1** **Area entry.** Obtain exercise-control clearance before entering an area for which clearance is required. Apply the exceptions and limitations in the assigned mission briefing.


<div id="position-content-0-2-2-1"><p class="label">3.2.2</p>
<ol type="a" start="1">
<li>Identify the requested area and intended activity.
</li>
<li>Read back the clearance and its limits.
</li>
<li>Report clear of the area when the assigned activity is complete.
</li>
</ol></div>

### 4 Airfield procedures

<a id="node-north-field"></a>

#### 4.1 NORTH FIELD

<a id="node-departure"></a>

**4.1.1** **Departure.** Follow local control instructions and the departure route assigned in the flight briefing.


<a id="position-content-0-3-0-1"></a>

**4.1.2** **Entry into controlled exercise airspace.** Local departure clearance does not replace the area-entry procedure in [Part I, Paragraph 3.2.1](#node-area-entry).


<a id="position-content-0-3-0-2"></a>

**4.1.3** **Recovery.** Coordinate the arrival with local control. Use the recovery and alternate instructions in the flight briefing.
